# Cab-Booking-and-Fare-Management-Mini-Project
It's an Cab Booking for travel by choosing an option and Enter a OTP to Book a Ride and See the Ride History and Search Ride by Customer Name and Find the Revenue Report from Cab Driving, Find the Longest Ride and Highest Fare using Functions, Lambda Functions, Loops like For, While and Input Variables and IF Statements like IF, IF - Else, Elif and For OTP Generation Random Library is Used.
